# Federated Learning

연합학습 관련 보고서와 논문을 읽고 이해한 내용, 발표 자료, 남은 질문을 기록합니다.

## 학습 기록

| 자료 | 진행 상황 |
|---|---|
| 연합학습 기술동향 보고서 | 학습 및 발표 완료 |
| 연합학습 시 글로벌 모델 성능 향상을 위한 기여도 기반 집계 알고리즘 | 학습 및 발표 완료 |

## 현재 관심 있는 질문

- 클라이언트 기여도와 라운드별 변화가 기관의 데이터 특징을 추론하는 단서가 될까?
- 악의적인 클라이언트가 높은 기여도를 받으면서 특정 예측을 왜곡할 수 있을까?

이 질문들은 발표에서 제시한 연구 아이디어이며, 직접 실험으로 검증한 결과는 아직 없습니다.
