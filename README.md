# Federated Learning

연합학습을 공부하면서 이해한 개념, 읽은 자료, 학습 중 생긴 질문을 기록하는 저장소입니다.

이 저장소는 직접 작성한 학술논문이나 연구 성과를 게시하기 위한 공간이 아니라, 학부생으로서 전공 지식을 쌓고 연구 주제를 탐색하는 과정을 기록하기 위한 공간입니다.

## 학습 기록

| 순서 | 학습 주제 | 참고 자료 | 상태 |
|---|---|---|---|
| 01 | 연합학습 기초지식 | 연합학습 기술동향 보고서 | 학습 및 발표 |
| 02 | Shapley-Based Aggregation | 연합학습 시 글로벌 모델 성능 향상을 위한 기여도 기반 집계 알고리즘 | 학습 및 발표 |

## 현재 관심 있는 질문

- 클라이언트 기여도와 라운드별 변화가 기관의 데이터 특징을 추론하는 단서가 될까?
- 악의적인 클라이언트가 높은 기여도를 받으면서 특정 예측을 왜곡할 수 있을까?
